# Solver: Find and Count Solutions Implementation Plan (#48)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@sudoku/core` exports `solve()`. It counts the solutions of a puzzle up to two, and returns the solution when there is exactly one.

**Architecture:** One pure module `packages/sudoku-core/src/solver.ts`. It is a bitmask backtracking search. Each step picks the empty cell with the fewest candidates. The search stops at the second solution. The row, column and box index tables are module constants inside `solver.ts`. A new `types.ts` holds the shared `Grid` type.

**Tech Stack:** TypeScript 6 (strict, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`), Vitest 5.0.3, pnpm workspace.

**Spec:** GitHub issue #48 (`gh issue view 48`). Background: ADR-011 point 1 (the backtracking solver), SUD-04.

## Review Focus

1. **Givens that conflict only through the search (no direct duplicate).** A puzzle where one empty cell has no candidate must give `{ count: 0 }` quickly, not search forever. Test: the "dead cell" puzzle in Task 1.
2. **The empty grid and near-empty grids.** These have very many solutions. The search must stop at the second and return `{ count: 2 }` fast. Test: the empty grid in Task 1.
3. **A full, valid grid.** It has no empty cell. It must return `{ count: 1 }` with a copy of itself. Test in Task 1.
4. **The caller's array.** A caller (the generator #35, the game #49) keeps using the puzzle after the call. `solve()` must not change it, and the returned solution must be a new array. Test in Task 1.
5. **Bad input from a scan.** A scan (#27) can hand over a value outside 0–9, `NaN`, a fraction or a short array. Each must throw a `RangeError`, not return a wrong count. Tests in Task 1.

```ts
import type { Grid } from './types'

/** count 2 means two or more: the search stops at the second solution. */
export type SolveResult = { count: 0 } | { count: 1; solution: Grid } | { count: 2 }

const CELLS = 81
const ALL_DIGITS = 0b11_1111_1110

const ROW_OF: readonly number[] = Array.from({ length: CELLS }, (_, cell) => Math.floor(cell / 9))
const COL_OF: readonly number[] = Array.from({ length: CELLS }, (_, cell) => cell % 9)
const BOX_OF: readonly number[] = Array.from(
  { length: CELLS },
  (_, cell) => Math.floor(cell / 27) * 3 + Math.floor((cell % 9) / 3),
)

function bitCount(mask: number): number {
  let count = 0
  for (let rest = mask; rest !== 0; rest &= rest - 1) count++
  return count
}

/**
 * Backtracking solver of ADR-011. Bit d of a mask stands for digit d.
 * Throws a RangeError for a puzzle that is not 81 integers from 0 to 9.
 */
export function solve(puzzle: readonly number[]): SolveResult {
  if (puzzle.length !== CELLS) {
    throw new RangeError(`A puzzle has ${CELLS} cells, not ${puzzle.length}`)
  }
  const cells: Grid = Array.from({ length: CELLS }, () => 0)
  const rows = Array.from({ length: 9 }, () => 0)
  const cols = Array.from({ length: 9 }, () => 0)
  const boxes = Array.from({ length: 9 }, () => 0)

  for (let cell = 0; cell < CELLS; cell++) {
    const digit = puzzle[cell]!
    if (!Number.isInteger(digit) || digit < 0 || digit > 9) {
      throw new RangeError(`Cell ${cell} holds ${digit}, not an integer from 0 to 9`)
    }
    if (digit === 0) continue
    const bit = 1 << digit
    const row = ROW_OF[cell]!
    const col = COL_OF[cell]!
    const box = BOX_OF[cell]!
    if ((rows[row]! | cols[col]! | boxes[box]!) & bit) return { count: 0 }
    rows[row]! |= bit
    cols[col]! |= bit
    boxes[box]! |= bit
    cells[cell] = digit
  }

  let count = 0
  let solution: Grid | undefined

  // Returns true when the search can stop: it found the second solution.
  function search(): boolean {
    let best = -1
    let bestMask = 0
    let bestCount = 10
    for (let cell = 0; cell < CELLS; cell++) {
      if (cells[cell] !== 0) continue
      const mask = ALL_DIGITS & ~(rows[ROW_OF[cell]!]! | cols[COL_OF[cell]!]! | boxes[BOX_OF[cell]!]!)
      const candidates = bitCount(mask)
      if (candidates < bestCount) {
        best = cell
        bestMask = mask
        bestCount = candidates
        if (candidates <= 1) break
      }
    }
    if (best === -1) {
      count++
      if (count === 1) solution = [...cells]
      return count >= 2
    }
    if (bestCount === 0) return false

    const row = ROW_OF[best]!
    const col = COL_OF[best]!
    const box = BOX_OF[best]!
    for (let rest = bestMask; rest !== 0; ) {
      const bit = rest & -rest
      rest ^= bit
      cells[best] = 31 - Math.clz32(bit)
      rows[row]! |= bit
      cols[col]! |= bit
      boxes[box]! |= bit
      const stop = search()
      cells[best] = 0
      rows[row]! &= ~bit
      cols[col]! &= ~bit
      boxes[box]! &= ~bit
      if (stop) return true
    }
    return false
  }

  search()
  if (count === 0) return { count: 0 }
  if (count === 1 && solution) return { count: 1, solution }
  return { count: 2 }
}
```

If `oxlint` or `tsc` refuses the `!` non-null assertions on compound assignments (`rows[row]! |= bit`), use a local: `rows[row] = rows[row]! | bit`. Keep the logic the same.
