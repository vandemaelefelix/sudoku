# Game Over Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** End the game at the third mistake on the screen side. A mistake gives a warning haptic. A lost game shows the **game over sheet** of the design canvas: a light scrim, a sheet that rises, "Out of mistakes", the number of right cells and the time, and three buttons: "Try this puzzle again", "New puzzle" and "Back to home". With Reduce Motion on, the sheet appears without the rise.

**Architecture:** The rule stays in the core. `place` already sets `status: 'lost'` at `MAX_MISTAKES`, the clock already stops when the status is not `playing`, and #37 already locks the tools and the keypad. This issue adds four things:

1. `rightCells(game)` in a new `src/game/utils/result.utils.ts`: the cells whose given or entry matches the solution (`valueAt` of the core).
2. A warning haptic in `MistakeDots`: an effect on `move` that fires when `move.mistake` is true.
3. A new `GameOverSheet` component. A gate reads `useGameState()` and renders nothing until the status is `lost`. The inner sheet reads the time, the theme and Reduce Motion. One shared value `rise` (1 to 0) drives the opacity and a 28 pt `translateY` with `withTiming`. With Reduce Motion, `rise` starts at 0 and no timing runs.
4. `GameScreen` mounts the sheet over the screen. "Try this puzzle again" restarts the same puzzle from the core: `GameScreen` keeps a `round` counter and gives `GameProvider` the key `round`. A new key mounts a new provider, so `useGameSession` calls `startSession(start)`, which calls `createGame` of the core. No session or core code changes. "Back to home" calls the existing `onBack`. "New puzzle" calls a new prop `onNewPuzzle`, which #51 provides.

**Tech Stack:** Expo 57, React Native 0.86, React 19, react-native-reanimated 4.5.1 (`useSharedValue`, `useAnimatedStyle`, `withTiming`, `Easing`, `useReducedMotion`, `Animated.View`), react-native-unistyles 3.5.2, expo-haptics 57.0.3 (`notificationAsync`, `NotificationFeedbackType.Warning`, read from the installed `build/Haptics.d.ts` of SDK 57), Jest 29 + @testing-library/react-native 13, `@sudoku/core`.

**Spec:** issue #40 (`gh issue view 40`). The design canvas `Main.dc.html` (https://claude.ai/artifact/U23JHiGA1Pq3HJX6oMiBF4), scenario `gameOver`:

- Scrim: `position: absolute; inset: 0; align-items: flex-end; padding: 0 12px 30px; background: T.overScrim` (the theme token `colors.scrim`).
- Sheet: `padding: 24px 20px 14px; gap: 6px; border-radius: 26px; background: T.surface; border: 1px solid T.line; box-shadow: 0 24px 60px -20px rgba(0,0,0,.35)` (`elevation.sheet`), `animation: rise .35s ease-out` with `@keyframes rise{from{transform:translateY(28px);opacity:0}to{transform:none;opacity:1}}`, and `prefers-reduced-motion: reduce` turns the animation off.
- Title "Out of mistakes", 22 pt bold. Body, 15 pt muted: "Three wrong numbers end this game. You had {N} of 81 cells right after {mm:ss}." The canvas counts `vals[i] === SOL[i]`, so givens count.
- Buttons: "Try this puzzle again" (accent, 50 pt, `margin-top: 14px`), "New puzzle" (outlined, 48 pt), "Back to home" (text only, muted, 44 pt).
- `retry()` resets the board to the puzzle, the mistakes to 0 and the time to 0.

Also `docs/architecture/00-concepts/game-screen.md` (States: Game over, `GameOver --> Playing: try this puzzle again`), glossary terms "Game over sheet" and "Mistake" (both present), ADR-015.

```ts
import { GRID_CELLS, valueAt, type Game } from '@sudoku/core'

/** The cells whose given or entry matches the solution. Givens count, as on the design canvas. */
export function rightCells(game: Game): number {
  let right = 0
  for (let cell = 0; cell < GRID_CELLS; cell++) {
    if (valueAt(game, cell) === game.solution[cell]) right += 1
  }
  return right
}
```

```tsx
import * as Haptics from 'expo-haptics'
import { useEffect } from 'react'
import { View } from 'react-native'
import { MAX_MISTAKES } from '@sudoku/core'
import { useGameState } from '@/game/hooks/useGameState'
import { styles } from './MistakeDots.styles'

const DOTS = Array.from({ length: MAX_MISTAKES }, (_, dot) => dot)

/** One dot fills for each mistake. A warning haptic goes with each new mistake. */
export function MistakeDots() {
  const { board, move } = useGameState()
  const { mistakes } = board
  useEffect(() => {
    if (!move?.mistake) return
    // A phone without a haptic engine rejects the call. The game goes on without the warning.
    Haptics.notificationAsync(Haptics.NotificationFeedbackType.Warning).catch(() => undefined)
  }, [move])
  return (
    <View style={styles.dots} accessible accessibilityLabel={`${mistakes} of ${MAX_MISTAKES} mistakes`}>
      {DOTS.map((dot) => (
        <View
          key={dot}
          testID={`mistake-dot-${dot}`}
          style={[styles.dot, dot < mistakes ? styles.filled : styles.empty]}
        />
      ))}
    </View>
  )
}
```

```tsx
import { useEffect } from 'react'
import { Pressable, Text, View } from 'react-native'
import Animated, { Easing, useAnimatedStyle, useReducedMotion, useSharedValue, withTiming } from 'react-native-reanimated'
import { useUnistyles } from 'react-native-unistyles'
import { GRID_CELLS, type Game } from '@sudoku/core'
import { useGameState } from '@/game/hooks/useGameState'
import { useGameTime } from '@/game/hooks/useGameTime'
import { rightCells } from '@/game/utils/result.utils'
import { formatClock } from '@/game/utils/time.utils'
import { RISE_OFFSET } from './GameOverSheet.constants'
import { styles } from './GameOverSheet.styles'

type GameOverSheetProps = {
  onRetry(): void
  /** Without it, the sheet has no New puzzle button. */
  onNewPuzzle?: () => void
  onHome(): void
}

/** Renders nothing until the game is lost. This gate reads no time and no theme, so a tick or a theme switch does not render it. */
export function GameOverSheet(props: GameOverSheetProps) {
  const { board } = useGameState()
  if (board.status !== 'lost') return null
  return <Sheet board={board} {...props} />
}

function Sheet({ board, onRetry, onNewPuzzle, onHome }: GameOverSheetProps & { board: Game }) {
  const time = formatClock(useGameTime())
  const { theme } = useUnistyles()
  const reduceMotion = useReducedMotion()
  // 1 is the start of the rise and 0 its end. With Reduce Motion the sheet starts at its end.
  const rise = useSharedValue(reduceMotion ? 0 : 1)
  useEffect(() => {
    if (reduceMotion) return
    rise.set(withTiming(0, { duration: theme.motion.medium, easing: Easing.out(Easing.quad) }))
  }, [reduceMotion, rise, theme.motion.medium])
  const riseStyle = useAnimatedStyle(() => ({
    opacity: 1 - rise.value,
    transform: [{ translateY: rise.value * RISE_OFFSET }],
  }))
  return (
    <View testID="game-over" style={styles.scrim} accessibilityViewIsModal>
      <Animated.View testID="game-over-sheet" style={[styles.sheet, riseStyle]}>
        <Text accessibilityRole="header" style={styles.title}>
          Out of mistakes
        </Text>
        <Text style={styles.body}>
          {`Three wrong numbers end this game. You had ${rightCells(board)} of ${GRID_CELLS} cells right after ${time}.`}
        </Text>
        <Pressable accessibilityRole="button" onPress={onRetry} style={styles.retry}>
          <Text style={styles.retryText}>Try this puzzle again</Text>
        </Pressable>
        {onNewPuzzle && (
          <Pressable accessibilityRole="button" onPress={onNewPuzzle} style={styles.newPuzzle}>
            <Text style={styles.newPuzzleText}>New puzzle</Text>
          </Pressable>
        )}
        <Pressable accessibilityRole="button" onPress={onHome} style={styles.home}>
          <Text style={styles.homeText}>Back to home</Text>
        </Pressable>
      </Animated.View>
    </View>
  )
}
```

```tsx
import { useCallback, useState } from 'react'
import { View } from 'react-native'
import type { NewGame } from '@sudoku/core'
import { Board } from '@/game/components/Board'
import { GameOverSheet } from '@/game/components/GameOverSheet'
import { GameProvider } from '@/game/components/GameProvider'
import { Header } from '@/game/components/Header'
import { Keypad } from '@/game/components/Keypad'
import { ThemeStatusBar } from '@/game/components/ThemeStatusBar'
import { Tools } from '@/game/components/Tools'
import { styles } from './GameScreen.styles'

type GameScreenProps = {
  start: NewGame
  /** The header back button and Back to home on the game over sheet. */
  onBack(): void
  /** New puzzle on the game over sheet. Without it, the sheet has no New puzzle button. */
  onNewPuzzle?: () => void
}

/**
 * The game screen of the design canvas. GameProvider reads start once. Give the screen a new React key for a new puzzle.
 * Try this puzzle again gives GameProvider a new key, so the core creates the game from start again.
 * The screen reads no theme hook, so a theme switch does not render the grid again (ADR-015).
 */
export function GameScreen({ start, onBack, onNewPuzzle }: GameScreenProps) {
  const [round, setRound] = useState(0)
  const retry = useCallback(() => setRound((previous) => previous + 1), [])
  return (
    <GameProvider key={round} start={start}>
      <ThemeStatusBar />
      <View style={styles.screen}>
        <Header onBack={onBack} />
        <Board />
        <Tools />
        <Keypad />
        <GameOverSheet onRetry={retry} onNewPuzzle={onNewPuzzle} onHome={onBack} />
      </View>
    </GameProvider>
  )
}
```

## Open questions

1. **The shared `expo-haptics` mock.** `jest.setup.ts` mocks only `impactAsync`. A mistake now calls `notificationAsync`, so any test that makes a mistake with `MistakeDots` mounted needs it. **Recommended:** let #40 add `notificationAsync: jest.fn(async () => undefined)` and `NotificationFeedbackType: { Warning: 'warning' }` to the shared mock (two lines, no other plan changes that mock), then drop the two local mocks. Until you rule, this plan uses local mocks in `MistakeDots.test.tsx` and `GameScreen.test.tsx`.
2. **Two haptics for one mistake.** `useMoveHaptics` (#42) gives a light tap for every placed number, a wrong one too. With this plan, a mistake gives the light tap and the warning together. **Recommended:** #42 skips the light tap when `move.mistake` is true, so a mistake feels different from a right number. #40 does not touch `useMoveHaptics`.
3. **Who wires New puzzle.** **Recommended:** merge #51 first, then rebase #40 and run Task 6. If #40 merges first, #51 passes `onNewPuzzle` and makes it required.
4. **Restart from the givens or from the start.** The issue says "restart from the givens". `start` of a scanned puzzle also holds the handwritten digits as entries (never mistakes). **Recommended:** restart from `start`, so a scanned puzzle keeps its handwritten digits. For a generated puzzle the two are the same. If you want the givens only, `GameScreen` passes `{ givens: start.givens, solution: start.solution }` to the provider after a retry.
5. **A lost game in History and in Continue.** ADR-012 lists lost games in History, and the home screen must not offer "Continue" for a lost game. Neither is in the acceptance criteria of #40. **Recommended:** the saving work (#36) records the result when the status becomes `lost` and clears the saved game. #40 adds nothing for it.
6. **Glossary.** No new term. "Game over sheet" and "Mistake" are already in `12-glossary.md`.
