# Save Games on the Device Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app saves the game in progress after every move and keeps a history of finished and lost games, in expo-sqlite behind `PuzzleRepository` and `HistoryRepository` (ADR-012).

**Architecture:** The repositories talk to a small `SqlDatabase` interface, which is the part of the expo-sqlite database that they use. On the iPhone, `openStorage()` hands them the real expo-sqlite database. In Jest, `openNodeDatabase()` hands them the SQLite that is built into Node 24, so the real SQL, the migrations and the transactions run in the tests. One contract suite runs against the SQLite repositories and against the in-memory fake, so the fake keeps the same rules. No screen uses the repositories yet. The game screen and the start screen wire them later.

**Tech Stack:** expo-sqlite 57 (`openDatabaseAsync`, `withExclusiveTransactionAsync`), expo-crypto 57 (`randomUUID`), `node:sqlite` (Jest only), `@sudoku/core` (`toSavedGame`, `fromSavedGame`), Jest with jest-expo.

**Spec:** GitHub issue #36 (`gh issue view 36`), ADR-012 (`docs/architecture/adr/adr-012-local-persistence.md`), QR-11 in `docs/architecture/10-quality-requirements.md`.

## Review Focus

1. **Saves fired one after another without `await`.** The game screen saves after every tap, so a second save can start before the first ends. Each save must land in order, and the last move must win. Two exclusive transactions on one connection must never overlap. Test: Task 3, "saves that run together land in their order" (it fails on the node adapter without the queue).
2. **A saved game that no longer loads** (an old version or damaged JSON). `current()` must not throw at app start. It soft-deletes the row and returns `null`. Test: Task 3, "a damaged saved game is discarded, not thrown".
3. **The app is killed after a move.** A new connection on the same file must return the last saved move and its time played. Test: Task 3, "resumes after the app is killed".
4. **A finished game saved twice** (a double tap on the last cell, or a save after the finish). The history must hold one row, not two. Test: Task 2, "saving a finished game twice adds one history entry".
5. **A database file from a newer app version.** `migrate()` must refuse it with a `RangeError` and must not write to it. A failed migration must roll back and keep the old version. Tests: Task 1, "refuses a database that is newer than the app" and "rolls back a migration that fails".

/** The part of an expo-sqlite database that the repositories use. Values go in as `?` parameters, never into the SQL text. */
export type SqlExecutor = {
  execAsync(source: string): Promise<void>
  runAsync(source: string, params: SqlValue[]): Promise<{ changes: number }>
  getFirstAsync<T>(source: string, params: SqlValue[]): Promise<T | null>
  getAllAsync<T>(source: string, params: SqlValue[]): Promise<T[]>
}

export type SqlDatabase = SqlExecutor & {
  /** Only the statements on `txn` belong to the transaction. A throw in `task` rolls it back. */
  withExclusiveTransactionAsync(task: (txn: SqlExecutor) => Promise<void>): Promise<void>
}

`apps/mobile/src/storage/nodeDatabase.ts`:

```ts
import type { SqlDatabase, SqlExecutor, SqlValue } from './sql.types'

type NodeStatement = {
  run(...params: SqlValue[]): { changes: number | bigint }
  get(...params: SqlValue[]): unknown
  all(...params: SqlValue[]): unknown[]
}

type NodeDatabaseSync = {
  exec(source: string): void
  prepare(source: string): NodeStatement
  close(): void
}

export type NodeDatabase = SqlDatabase & { close(): void }

/**
 * A SqlDatabase on the SQLite that Node 24 has built in, for Jest only: expo-sqlite is native.
 * `path` is a file, or ':memory:'. The app never imports this file.
 */
export function openNodeDatabase(path: string): NodeDatabase {
  const { DatabaseSync } = require('node:sqlite') as {
    DatabaseSync: new (path: string) => NodeDatabaseSync
  }
  const db = new DatabaseSync(path)
  const executor: SqlExecutor = {
    async execAsync(source) {
      db.exec(source)
    },
    async runAsync(source, params) {
      return { changes: Number(db.prepare(source).run(...params).changes) }
    },
    async getFirstAsync<T>(source: string, params: SqlValue[]) {
      return (db.prepare(source).get(...params) as T | undefined) ?? null
    },
    async getAllAsync<T>(source: string, params: SqlValue[]) {
      return db.prepare(source).all(...params) as T[]
    },
  }
  return {
    ...executor,
    async withExclusiveTransactionAsync(task) {
      db.exec('BEGIN IMMEDIATE')
      try {
        await task(executor)
        db.exec('COMMIT')
      } catch (error) {
        db.exec('ROLLBACK')
        throw error
      }
    },
    close: () => db.close(),
  }
}

/** A path for a database file in the temporary folder, and a way to remove the file after the test. */
export function temporaryDatabaseFile(): { path: string; remove(): void } {
  const { tmpdir } = require('node:os') as { tmpdir(): string }
  const { join } = require('node:path') as { join(...parts: string[]): string }
  const { rmSync } = require('node:fs') as { rmSync(path: string, options: { force: boolean }): void }
  const path = join(tmpdir(), `sudoku-${process.pid}-${Date.now()}-${Math.random().toString(36).slice(2)}.db`)
  return { path, remove: () => rmSync(path, { force: true }) }
}
```

`apps/mobile/src/storage/migrations.ts`:

```ts
import type { SqlDatabase } from './sql.types'

const LEVELS = "('easy', 'medium', 'hard', 'expert')"
const SOURCES = "('generated', 'scanned')"

/**
 * Migration N is the SQL at index N - 1. PRAGMA user_version holds the last migration that ran (ADR-012).
 * Append a new migration. Never change one that shipped.
 */
export const MIGRATIONS: readonly string[] = [
  `CREATE TABLE game_in_progress (
    id TEXT PRIMARY KEY NOT NULL,
    level TEXT NOT NULL CHECK (level IN ${LEVELS}),
    source TEXT NOT NULL CHECK (source IN ${SOURCES}),
    saved_game TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    deleted_at TEXT
  );
  CREATE TABLE game_history (
    id TEXT PRIMARY KEY NOT NULL,
    level TEXT NOT NULL CHECK (level IN ${LEVELS}),
    source TEXT NOT NULL CHECK (source IN ${SOURCES}),
    result TEXT NOT NULL CHECK (result IN ('won', 'lost')),
    played_ms INTEGER NOT NULL CHECK (played_ms >= 0),
    mistakes INTEGER NOT NULL CHECK (mistakes >= 0),
    hints_used INTEGER NOT NULL CHECK (hints_used >= 0),
    finished_at TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    deleted_at TEXT
  );
  CREATE INDEX game_history_best_time ON game_history (level, result, played_ms) WHERE deleted_at IS NULL;`,
]

/**
 * Runs each migration that is newer than the database, each in its own transaction.
 * Returns the schema version. Throws a RangeError, and writes nothing, when the database is newer than the app.
 */
export async function migrate(db: SqlDatabase, migrations: readonly string[] = MIGRATIONS): Promise<number> {
  const row = await db.getFirstAsync<{ user_version: number }>('PRAGMA user_version', [])
  const current = row?.user_version ?? 0
  if (current > migrations.length) {
    throw new RangeError(`The database version ${current} is newer than this app (${migrations.length})`)
  }
  for (let next = current + 1; next <= migrations.length; next++) {
    const source = migrations[next - 1]
    await db.withExclusiveTransactionAsync(async (txn) => {
      await txn.execAsync(source)
      await txn.execAsync(`PRAGMA user_version = ${next}`)
    })
  }
  return migrations.length
}
```

import type { Game } from '@sudoku/core'
import type { GameResult, Level, PuzzleSource, SavedProgress } from './storage.types'

/** The game in progress (ADR-012). Screens use this interface, never SQL. */
export type PuzzleRepository = {
  /** Starts a game in progress and discards the one before it. Throws a RangeError for a won or lost game. */
  start(input: { level: Level; source: PuzzleSource; game: Game }): Promise<SavedProgress>
  /** The game in progress, or null. A saved game that no longer loads is discarded and gives null. */
  current(): Promise<SavedProgress | null>
  /**
   * Saves the game after a move. A won or lost game moves to the history in the same transaction.
   * Does nothing when `id` is not the game in progress.
   */
  save(id: string, game: Game): Promise<void>
  discard(id: string): Promise<void>
}

export function resultOf(game: Game): GameResult | null {
  return game.status === 'won' || game.status === 'lost' ? game.status : null
}
```

import { createGame, place, select, tick, type Game } from '@sudoku/core'
import type { GameStorage, StorageDeps } from './storage.types'

// The puzzle of the design canvas. Cell 2 is empty and needs a 4.
const GIVENS = digits('530070000600195000098000060800060003400803001700020006060000280000419005000080079')
const SOLUTION = digits('534678912672195348198342567859761423426853791713924856961537284287419635345286179')

function digits(text: string): number[] {
  return [...text].map(Number)
}

export function newGame(): Game {
  return createGame({ givens: GIVENS, solution: SOLUTION })
}

/** Every open cell is filled except cell 2. */
function nearlyWon(): Game {
  const entries = SOLUTION.map((digit, cell) => (GIVENS[cell] === 0 && cell !== 2 ? digit : 0))
  return select(createGame({ givens: GIVENS, solution: SOLUTION, entries }), 2)
}

export function wonGame(playedMs: number): Game {
  return place(tick(nearlyWon(), playedMs), 4).game
}

/** Three wrong numbers in cell 2. */
export function lostGame(playedMs: number): Game {
  let game = select(tick(newGame(), playedMs), 2)
  for (const digit of [1, 2, 3] as const) game = place(game, digit).game
  return game
}

export function testDeps(): StorageDeps {
  let ids = 0
  let seconds = 0
  return {
    newId: () => `game-${++ids}`,
    now: () => new Date(Date.UTC(2026, 9, 12, 9, 0, seconds++)).toISOString(),
  }
}

/** The rules every GameStorage keeps: the SQLite one and the in-memory fake. */
export function describeGameStorage(name: string, open: (deps: StorageDeps) => Promise<GameStorage>): void {
  describe(name, () => {
    let storage: GameStorage

    beforeEach(async () => {
      storage = await open(testDeps())
    })

    it('has no game in progress at first', async () => {
      await expect(storage.puzzles.current()).resolves.toBeNull()
    })

    it('returns the game it started', async () => {
      const game = newGame()
      const started = await storage.puzzles.start({ level: 'easy', source: 'generated', game })
      expect(started).toEqual({ id: 'game-1', level: 'easy', source: 'generated', game })
      await expect(storage.puzzles.current()).resolves.toEqual(started)
    })

    it('discards the game in progress when a new one starts', async () => {
      const first = await storage.puzzles.start({ level: 'easy', source: 'generated', game: newGame() })
      const second = await storage.puzzles.start({ level: 'hard', source: 'scanned', game: newGame() })
      await storage.puzzles.save(first.id, tick(newGame(), 5_000))
      await expect(storage.puzzles.current()).resolves.toEqual(second)
    })

    it('refuses to start a won or a lost game', async () => {
      await expect(
        storage.puzzles.start({ level: 'easy', source: 'generated', game: wonGame(1_000) }),
      ).rejects.toThrow(RangeError)
      await expect(
        storage.puzzles.start({ level: 'easy', source: 'generated', game: lostGame(1_000) }),
      ).rejects.toThrow(RangeError)
    })

    it('keeps the last move and the time played', async () => {
      const { id } = await storage.puzzles.start({ level: 'medium', source: 'generated', game: newGame() })
      const moved = place(select(tick(newGame(), 61_000), 2), 4).game
      await storage.puzzles.save(id, moved)
      const current = await storage.puzzles.current()
      expect(current?.game).toEqual(moved)
      expect(current?.game.playedMs).toBe(61_000)
    })

    it('moves a won game to the history', async () => {
      const { id } = await storage.puzzles.start({ level: 'hard', source: 'scanned', game: nearlyWon() })
      await storage.puzzles.save(id, wonGame(90_000))
      await expect(storage.puzzles.current()).resolves.toBeNull()
      await expect(storage.history.list()).resolves.toEqual([
        {
          id,
          level: 'hard',
          source: 'scanned',
          result: 'won',
          playedMs: 90_000,
          mistakes: 0,
          hintsUsed: 0,
          finishedAt: expect.any(String),
        },
      ])
    })

    it('moves a lost game to the history', async () => {
      const { id } = await storage.puzzles.start({ level: 'easy', source: 'generated', game: newGame() })
      await storage.puzzles.save(id, lostGame(30_000))
      const [entry] = await storage.history.list()
      expect(entry).toMatchObject({ id, result: 'lost', mistakes: 3, playedMs: 30_000 })
    })

    it('saving a finished game twice adds one history entry', async () => {
      const { id } = await storage.puzzles.start({ level: 'easy', source: 'generated', game: nearlyWon() })
      await storage.puzzles.save(id, wonGame(40_000))
      await storage.puzzles.save(id, wonGame(40_000))
      await expect(storage.history.list()).resolves.toHaveLength(1)
    })

    it('discards a game without a history entry', async () => {
      const { id } = await storage.puzzles.start({ level: 'easy', source: 'generated', game: newGame() })
      await storage.puzzles.discard(id)
      await expect(storage.puzzles.current()).resolves.toBeNull()
      await expect(storage.history.list()).resolves.toEqual([])
    })

import { fromSavedGame, toSavedGame, type SavedGame } from '@sudoku/core'
import type { BestTimes, HistoryRepository } from './HistoryRepository'
import { resultOf, type PuzzleRepository } from './PuzzleRepository'
import type { GameStorage, HistoryEntry, Level, PuzzleSource, StorageDeps } from './storage.types'

type Progress = { id: string; level: Level; source: PuzzleSource; saved: SavedGame }

function countingDeps(): StorageDeps {
  let ids = 0
  let seconds = 0
  return {
    newId: () => `game-${++ids}`,
    now: () => new Date(Date.UTC(2026, 0, 1, 0, 0, seconds++)).toISOString(),
  }
}

/** The in-memory fake of the game storage for Jest (ADR-012). It keeps the rules of the SQLite repositories. */
export function createMemoryStorage(deps: StorageDeps = countingDeps()): GameStorage {
  let progress: Progress | null = null
  // Newest first.
  const entries: HistoryEntry[] = []

  const puzzles: PuzzleRepository = {
    async start({ level, source, game }) {
      if (resultOf(game) !== null) throw new RangeError(`A ${game.status} game cannot start`)
      progress = { id: deps.newId(), level, source, saved: toSavedGame(game) }
      return { id: progress.id, level, source, game }
    },
    async current() {
      if (progress === null) return null
      return { id: progress.id, level: progress.level, source: progress.source, game: fromSavedGame(progress.saved) }
    },
    async save(id, game) {
      if (progress === null || progress.id !== id) return
      const result = resultOf(game)
      if (result === null) {
        progress = { ...progress, saved: toSavedGame(game) }
        return
      }
      entries.unshift({
        id,
        level: progress.level,
        source: progress.source,
        result,
        playedMs: game.playedMs,
        mistakes: game.mistakes,
        hintsUsed: game.hintsUsed,
        finishedAt: deps.now(),
      })
      progress = null
    },
    async discard(id) {
      if (progress?.id === id) progress = null
    },
  }

  const history: HistoryRepository = {
    async list() {
      return [...entries]
    },
    async bestTimes() {
      const best: BestTimes = {}
      for (const entry of entries) {
        const time = best[entry.level]
        if (entry.result === 'won' && (time === undefined || entry.playedMs < time)) {
          best[entry.level] = entry.playedMs
        }
      }
      return best
    },
  }

  return { puzzles, history }
}
```

```ts
type ProgressRow = { id: string; level: Level; source: PuzzleSource; saved_game: string }

/** Runs each task after the one before. Two exclusive transactions on one connection must not overlap. */
function createQueue() {
  let last: Promise<unknown> = Promise.resolve()
  return <T>(task: () => Promise<T>): Promise<T> => {
    const next = last.then(task, task)
    last = next.catch(() => undefined)
    return next
  }
}

export function createSqlitePuzzleRepository(db: SqlDatabase, deps: StorageDeps): PuzzleRepository {
  const inOrder = createQueue()

  return {
    start: ({ level, source, game }) =>
      inOrder(async () => {
        if (resultOf(game) !== null) throw new RangeError(`A ${game.status} game cannot start`)
        const id = deps.newId()
        const now = deps.now()
        await db.withExclusiveTransactionAsync(async (txn) => {
          await txn.runAsync(
            'UPDATE game_in_progress SET deleted_at = ?, updated_at = ? WHERE deleted_at IS NULL',
            [now, now],
          )
          await txn.runAsync(
            `INSERT INTO game_in_progress (id, level, source, saved_game, created_at, updated_at)
              VALUES (?, ?, ?, ?, ?, ?)`,
            [id, level, source, JSON.stringify(toSavedGame(game)), now, now],
          )
        })
        return { id, level, source, game }
      }),

    current: () =>
      inOrder(async () => {
        const row = await db.getFirstAsync<ProgressRow>(
          `SELECT id, level, source, saved_game FROM game_in_progress
            WHERE deleted_at IS NULL ORDER BY created_at DESC LIMIT 1`,
          [],
        )
        if (row === null) return null
        try {
          const game = fromSavedGame(JSON.parse(row.saved_game))
          return { id: row.id, level: row.level, source: row.source, game }
        } catch (error) {
          devWarn('storage', `The saved game ${row.id} does not load: ${errorMessage(error)}`)
          const now = deps.now()
          await db.runAsync('UPDATE game_in_progress SET deleted_at = ?, updated_at = ? WHERE id = ?', [
            now,
            now,
            row.id,
          ])
          return null
        }
      }),

    save: (id, game) =>
      inOrder(() =>
        db.withExclusiveTransactionAsync(async (txn) => {
          const row = await txn.getFirstAsync<Pick<ProgressRow, 'level' | 'source'>>(
            'SELECT level, source FROM game_in_progress WHERE id = ? AND deleted_at IS NULL',
            [id],
          )
          if (row === null) return
          const now = deps.now()
          const result = resultOf(game)
          await txn.runAsync(
            'UPDATE game_in_progress SET saved_game = ?, updated_at = ?, deleted_at = ? WHERE id = ?',
            [JSON.stringify(toSavedGame(game)), now, result === null ? null : now, id],
          )
          if (result !== null) {
            await insertHistoryEntry(txn, {
              id,
              level: row.level,
              source: row.source,
              result,
              playedMs: game.playedMs,
              mistakes: game.mistakes,
              hintsUsed: game.hintsUsed,
              finishedAt: now,
            })
          }
        }),
      ),

    discard: (id) =>
      inOrder(async () => {
        const now = deps.now()
        await db.runAsync(
          'UPDATE game_in_progress SET deleted_at = ?, updated_at = ? WHERE id = ? AND deleted_at IS NULL',
          [now, now, id],
        )
      }),
  }
}
```
